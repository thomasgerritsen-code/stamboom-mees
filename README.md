# Stamboom Mees

Familiestamboom van Mees Gerritsen Kroon, als web-app.

Open de app via GitHub Pages en vul de toegangscode in. De inhoud van `index.html` is versleuteld (AES-256-GCM); zonder code is er niets te lezen.

Op de telefoon kun je de app op het beginscherm zetten:
- iPhone (Safari): Delen → Zet op beginscherm
- Android (Chrome): menu ⋮ → App installeren
